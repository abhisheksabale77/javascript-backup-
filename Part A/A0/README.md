# A0 — Setup &amp; Tools

**Time:** 3–5 days · **Priority:** `[B]` backend-critical

## Topics

- [ ] Editor (VS Code) installed and comfortable to use
- [ ] Node.js LTS installed — `node -v` and `npm -v` work
- [ ] npm basics: `npm init`, `npm install`, `package.json`
- [ ] Terminal basics: `cd`, `ls`/`dir`, `mkdir`, running commands
- [ ] Run JS three ways: `node file.js`, browser console, `<script>` tag
- [ ] Git basics: `git init`, `git add`, `git commit`, `git log`
- [ ] Chrome DevTools: console, sources, breakpoints
- [ ] Read stack traces
- [ ] `console.log` / `warn` / `error` / `table`

## Project

Debug 5 broken scripts (wrong variable names, missing brackets, bad logic, async mistake, scope mistake). Fix each one and explain the error out loud.

## Done when

- [ ] `node -v` and `npm -v` print versions
- [ ] You can run the same JS in Node and in the browser
- [ ] You can make a git commit from the terminal
- [ ] You can pause code with a DevTools breakpoint and inspect variables
- [ ] You can read a stack trace and point to the exact failing line
